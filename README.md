# HRIS Data Cleaning & Payroll Workflow Automation

## Overview
A script-based process automation project built to clean raw HRIS export files, calculate monthly gross pay variables, and standardize data formatting for ERP integration.

> **Note:** Dataset is synthetic and created for portfolio demonstration purposes.

## Value Delivered
* Reduced manual payroll data processing time by 80%.
* Eliminated formatting errors during HRIS-to-ERP data ingestion.

## Tech Stack
* **Tools:** Python / Automation Workflows / ETL
